The upstream EXIF advisory states no known workaround for the native decoder itself; predecode application rejection must be justified separately. [Official utility API](https://sharp.pixelplumbing.com/api-utility/#block), [EXIF advisory](https://github.com/libvips/libvips/security/advisories/GHSA-jmwm-wc68-mhwm).
